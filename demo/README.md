# SiliCAD / EDA_MCP Verification Demos

This directory contains standalone, production-grade UVM verification project demonstrations generated by the `uvm-architect` skill and agent, verified on Cadence EDA toolchains.

---

## 1. `demo/or_Gate`

A complete, production-grade UVM 1.2 verification environment for a 2-input combinational OR gate (`or_gate`), featuring:

- **Pure Synthesizable RTL**: [`rtl/or_gate.v`](or_Gate/rtl/or_gate.v) with zero verification code.
- **SystemVerilog Assertions (SVA)**: [`assertions/or_gate_assertions.sv`](or_Gate/assertions/or_gate_assertions.sv) bound non-intrusively using `bind`.
- **Full UVM Hierarchy**: 15 components in [`tb/`](or_Gate/tb/) (interface with synchronous sample strobes, driver, monitor, independent reference model, lockstep per-op scoreboard, 40-bin functional coverage subscriber, agent, env, virtual sequencer, virtual sequence, and `top.sv`).
- **Test Suite**: Directed exhaustive truth table, multi-seed random, and corner toggle tests in [`tests/`](or_Gate/tests/).
- **Cadence JasperGold Formal**: [`formal/run.jg`](or_Gate/formal/run.jg) with 7/7 unbounded proofs and 12/12 vacuity covers.
- **Automated Regression Suite**: [`scripts/run_regression.sh`](or_Gate/scripts/run_regression.sh) and [`scripts/run_regression.py`](or_Gate/scripts/run_regression.py) outputting 12-column metadata CSV and merging cumulative IMC coverage.
- **Authentic Mutation Testing**: [`scripts/run_mutation.py`](or_Gate/scripts/run_mutation.py) testing 11 syntactic mutants.
- **Documentation Suite**: Specification, requirements traceability matrix (vPlan), waivers, and signoff report in [`docs/`](or_Gate/docs/).

### How to Run on EDA Server
```bash
# 1. Formal Proofs
tcsh -c "source /cadence/cshrc; cd demo/or_Gate; jg -batch -tcl formal/run.jg >& formal/jaspergold_formal.log"

# 2. Automated Regression & IMC Coverage Merge
tcsh -c "source /cadence/cshrc; cd demo/or_Gate; ./scripts/run_regression.sh"

# 3. Authentic Mutation Testing
tcsh -c "source /cadence/cshrc; cd demo/or_Gate; python3 scripts/run_mutation.py"
```
